# 🔬 Transistor Logic Gate Kit

A hands-on **Transistor Logic Gate Kit** designed to help beginners, students, and electronics enthusiasts understand the fundamentals of **digital logic circuits using NPN and PNP transistors**.

Instead of learning logic gates only through truth tables and theory, this project provides a practical PCB-based platform for building, observing, and experimenting with transistor-level digital logic.

---

## 📌 Project Overview

This project demonstrates how **transistors can be used as electronic switches to implement basic digital logic gates**.

The kit allows users to explore fundamental logic operations such as:

* AND
* OR
* NOT
* NAND
* NOR

By experimenting with the physical circuit, users can understand how transistor switching behavior creates different logic outputs.

## 🧠 Logic Gates Demonstrated

The PCB can be used to understand the operation of several fundamental logic gates.

| Logic Gate | Function                                       |
| ---------- | ---------------------------------------------- |
| AND        | Output is HIGH when both inputs are HIGH       |
| OR         | Output is HIGH when at least one input is HIGH |
| NOT        | Output is the inverse of the input             |
| NAND       | Inverted AND operation                         |
| NOR        | Inverted OR operation                          |

## 🔌 How It Works

The kit demonstrates the fundamental concept of using a transistor as a **switch**.

Depending on the input signal, the transistor can operate in different states, allowing the circuit to represent digital **HIGH** and **LOW** logic levels.

Multiple transistor stages can then be combined to create different logic functions.

The project provides a practical way to connect:

```text
Transistor Switching
        ↓
Digital Logic
        ↓
Logic Gates
        ↓
Digital Electronics
```

## ⚠️ Important Notes

* This project is intended primarily for **educational and experimental purposes**.
* Verify the circuit and component values before manufacturing.
* Check transistor pin configurations carefully because transistor pinouts can vary between part numbers and manufacturers.
* Verify resistor values and supply voltage before powering the circuit.
* Run ERC/DRC checks before manufacturing.
* Do not exceed the recommended voltage or current ratings of the components.
* The physical PCB should be tested carefully before connecting it to other electronic equipment.
